# اپ فروشگاه کودک (BabyShopApp)

اپ اندروید برای پیج فروش مغازه بچگانه — با Kotlin و Jetpack Compose.

## امکانات

- **برای مشتری:** مشاهده محصولات با عکس و قیمت، فیلتر بر اساس دسته‌بندی (پسرانه/دخترانه/نوزاد/اسباب‌بازی/سایر)، سبد خرید، و ثبت سفارش با ارسال پیام آماده به **واتساپ** یا **تلگرام**.
- **برای فروشنده (بخش مدیریت):** افزودن، ویرایش و حذف محصول (نام، قیمت، عکس، دسته‌بندی، توضیحات، موجود/ناموجود)، تنظیم نام فروشگاه، شماره واتساپ فروشنده، و رمز عبور بخش مدیریت.
- تمام داده‌ها **محلی روی گوشی** ذخیره می‌شوند (پایگاه‌داده Room / SQLite) — نیازی به سرور یا اینترنت برای کار با اپ نیست (فقط برای ارسال سفارش به واتساپ/تلگرام اینترنت لازم است).

## چطور باز و اجرا کنم؟

1. [Android Studio](https://developer.android.com/studio) رو نصب کن (آخرین نسخه).
2. پوشه `BabyShopApp` رو با گزینه **Open** در Android Studio باز کن.
3. صبر کن Gradle Sync تموم بشه (بار اول ممکنه چند دقیقه طول بکشه چون وابستگی‌ها دانلود می‌شن — نیاز به اینترنت داره).
4. یک شبیه‌ساز (Emulator) بساز یا گوشی خودت رو با USB و حالت Developer/USB Debugging وصل کن.
5. دکمه **Run ▶** رو بزن.

## شخصی‌سازی قبل از استفاده واقعی

بعد از نصب اپ روی گوشی، وارد تب **مدیریت** شو (رمز پیش‌فرض: `1234`) و از قسمت **تنظیمات**:

- نام فروشگاه رو عوض کن.
- شماره واتساپ خودت رو با فرمت `کد کشور + شماره بدون صفر` وارد کن، مثلاً برای `0912xxxxxxx` بنویس: `989120000000`.
- رمز بخش مدیریت رو عوض کن.

سپس از تب مدیریت محصولات نمونه رو حذف کن و محصولات واقعی مغازه‌ات رو با عکس اضافه کن.

## نکته درباره ارسال سفارش با تلگرام

چون تلگرام اجازه نمی‌ده مستقیم و بدون ربات به یک مخاطب مشخص پیام از بیرون اپ فرستاد، دکمه «ارسال با تلگرام» پیام سفارش رو باز می‌کنه تا خود مشتری گیرنده (پیج/آیدی فروشگاه) رو انتخاب کنه. اگر تلگرام نصب نباشه، منوی اشتراک‌گذاری عمومی گوشی باز می‌شه.

## ساختار پروژه

```
app/src/main/java/com/example/babyshop/
├── MainActivity.kt
├── data/            # مدل محصول، Room database، تنظیمات
└── ui/
    ├── ShopViewModel.kt   # منطق اصلی (محصولات، سبد خرید)
    ├── AppNav.kt          # ناوبری بین صفحات
    └── screens/           # صفحات: لیست محصولات، جزئیات، سبد خرید، مدیریت
```

## ساخت APK آنلاین با GitHub Actions (بدون نصب هیچ برنامه‌ای)

این پروژه یه فایل تنظیمات (`.github/workflows/build.yml`) داره که به‌صورت خودکار APK می‌سازه. مراحل:

1. یک حساب رایگان توی [github.com](https://github.com) بساز (اگه نداری).
2. یک ریپازیتوری (repository) جدید بساز — دکمه سبز **"New"** یا **"+"** بالای صفحه، اسمش رو مثلاً `babyshop-app` بذار، Public یا Private فرقی نمی‌کنه، و روی **Create repository** بزن.
3. توی صفحه ریپازیتوری، لینک **"uploading an existing file"** رو بزن (یا از منوی Add file → Upload files).
4. کل محتویات پوشه `BabyShopApp` (نه خود پوشه، فایل‌ها و پوشه‌های داخلش) رو بکش و رها کن، بعد پایین صفحه دکمه **Commit changes** رو بزن.
   - نکته: آپلود وب گیت‌هاب پوشه‌های خالی یا فایل‌های مخفی (مثل `.github`) رو گاهی جا می‌ندازه. اگه فایل `.github/workflows/build.yml` توی ریپازیتوری دیده نشد، همون فایل رو جدا و مستقیم آپلود کن (از همون Add file → Upload files و مسیر `.github/workflows/build.yml` رو حفظ کن) یا از Git استفاده کن.
5. بعد از Commit، خودکار وارد تب **Actions** میشه (بالای صفحه ریپازیتوری) و می‌بینی که ساخت (build) شروع شده — چند دقیقه طول می‌کشه.
6. وقتی تیک سبز خورد، روی همون build کلیک کن، پایین صفحه بخش **Artifacts** رو ببین، و فایل `BabyShopApp-debug-apk` رو دانلود کن (یک zip حاوی APK).
7. فایل zip رو باز کن، `app-debug.apk` رو به گوشی اندرویدت منتقل کن و نصبش کن (باید اجازه «نصب از منابع ناشناس» رو در تنظیمات گوشی فعال کنی).

هر بار که فایلی از پروژه رو توی گیت‌هاب تغییر بدی و Commit کنی، یک APK جدید خودکار ساخته می‌شه.

- انتشار اپ روی Google Play (نیاز به حساب توسعه‌دهنده گوگل و امضای نسخه release داره).
